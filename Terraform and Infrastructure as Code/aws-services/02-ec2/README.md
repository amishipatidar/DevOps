# AWS EC2 (Elastic Compute Cloud)

Comprehensive guide on AWS EC2 virtual compute instances, AMI images, networking, and EBS storage.

## Key Concepts
- **What is EC2?**: Resizable virtual compute instances running Linux/Windows in the AWS cloud.
- **AMI (Amazon Machine Image)**: Pre-configured template containing OS, application server, and software packages.
- **Instance Types**: Categorized compute configurations (General Purpose `t3.micro`, Compute Optimized `c6g`, Memory `r6g`).
- **Key Pairs**: Asymmetric SSH public/private key pairs used to securely log into EC2 instances.
- **Security Groups**: Stateful virtual firewalls controlling inbound and outbound network traffic at instance level.
- **EBS (Elastic Block Store)**: Persistent block storage volumes attached to EC2 instances (`gp3`, `io2`).
- **Public vs Private IP**: Public IP (internet-routable) vs Private IP (internal VPC communications).
- **Instance Lifecycle**: Pending  Running  Stopping  Stopped  Terminated.
